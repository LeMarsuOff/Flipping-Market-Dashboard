Install instructions · ~2 minutes
01
Download FlippingMarketSync.ex5 from the button above
02
Open your MetaTrader 5 terminal
03
File → Open Data Folder → MQL5 → Experts
04
Copy the .ex5 file into this folder and restart MT5
05
Tools → Options → Expert Advisors → enable "Allow WebRequest" → add https://api.flipping-market.com
06
Drag the EA onto any chart, paste your sync token in the input parameters, click OK

Disconnect = soft state. Le sync token est révoqué côté serveur, mais les profils MT5 (FTMO Funded, FTMO Challenge) et leurs trades restent en base. Reconnect = paste un nouveau token dans l'EA → les profils se ré-attachent automatiquement. Hard delete intervient seulement après 12 mois d'inactivité user ou click explicite "Delete my account".
