## 1. Project Overview

Flipping Market Dashboard is a quantitative trading journal for SMC/M15 traders. It analyses Notion-backed trade data through KPI widgets, heatmaps, equity curves, and partial-TP simulators. Used personally by Max and distributed to ~600 community members via GitHub Pages.

## 4. Data Flow

```
Notion DB (user-owned)
  → OAuth handshake via Vercel backend
    → _fetchApiTrades() / incremental sync (last_edited_time cursor)
      → _normalizeAPITrade() → appState.trades.items[]
        → filterDataset() [line 4848]
          → individual widget renderers
            ↕ localStorage (preset slots, field names, theme, layout)
            ↕ Supabase (sync keys cross-device)
```

**Cache layers:**
- **In-memory:** `appState.trades.items` — raw + normalized trades, lost on page refresh
- **localStorage:** `apiFieldNames_v1` (field mapping), theme, layout JSON, preset snapshots
- **localStorage (stale risk):** `apiTradesCache_v2_rrmax_*` — purge after structural changes: `localStorage.removeItem('apiTradesCache_v2_rrmax_*')` + hard refresh
- **Supabase:** OAuth tokens, permanent media URLs, cross-device sync

## 5. Preset Architecture

A preset = a named filter configuration the user saves and switches between.

**localStorage keys:**
- `flipping_presets` — array of `{id, name}` metadata
- `flipping_preset_snapshots_v2` — per-preset snapshot: `{chips, customChips, tpConfig}`
- `presetLiveFilters_v1` — per-preset live slot: `{chips, customChips, comboFilters, rrMinFilter, tpConfig, poPresetSlots}`
- `gs_active_preset` — active preset ID

**Chip shape** (each of the 9+ native dims + custom dims):
```js
{ mode: 'neutral'|'include'|'exclude',
  included: Set, excluded: Set,
  includedFromPreset: Set, excludedFromPreset: Set }
```
`*FromPreset` sets tag values injected by the snapshot (rendered with a glow halo) vs live-clicked overrides.

**Key functions:** `applyPreset(id)` ~line 4500 · `savePresetLiveFilters()` · `savePresetSnapshots()` · `getPresetLiveSlot(id)` ~line 31358

**Invariant:** Never zero out `flipping_preset_snapshots_v2` without a migration. Breaking the snapshot schema silently destroys all user presets.

## 6. CSS Variable System

3-layer token architecture in `dashboard.css`:

**Layer A — Foundation (`:root`)**
- A1: Color palette — `--bg/bg1–4`, `--g/r/gold/a/b/t` + semantic tints (`--g2/g3`, `--r2/r3`, `--gold2/gold3`)
- A1c: Chart categorical palette — `--chart-cat-1` through `--chart-cat-8`
- A1d: Semantic overrides — `--oc-betp: #2962ff` (BE-TP blue), `--oc-besl: #b478f0` (BE-SL violet)
- A2–A8: Spacing scale, radius scale, shadow scale, border widths, easing, z-index scale, layout dims

**Layer B — Semantic:** `--app-bg`, `--surface-1–4`, `--text-primary/secondary/muted`, `--color-success/danger/warning/info`, `--accent-primary`

**Layer C — Component:** `--topbar-*`, `--chip-*`, `--preset-*`, `--kpi-*`, `--widget-*`, `--panel-*`, `--table-*`

**Typography — 15 groups** (`--typo-[group]-[prop]` where prop ∈ `size weight lh ls tt`):
`base` · `topbar-val/lbl` · `sidebar-lbl/chip` · `widget-title` · `widget-sub` · `kpi-val` · `kpi-lbl` · `chart-axis` · `chart-val` · `table-hd` · `table-body` · `panel` · `code` · `badge`

**Event:** `document.dispatchEvent(new CustomEvent('themeTypoChanged'))` fires after theme/typo changes. Widgets listen and redraw.

**Share-view typography** — scoped tokens `--sv-fs-{micro,small,body,header,week,week-val,kpi-val,display,kpi-big}` on `#share-view`. Never use `var(--typo-*)` or `vw/cqw/clamp()` in share-view CSS — unstable in dom-to-image foreignObject.

## 7. Code Conventions

- **Vanilla JS only.** No npm, no bundler, no framework. CDN links only (GridStack 10.3.1, Google Fonts).
- **Never hardcode colors.** Use CSS variables (`var(--g)`, `var(--r)`, `var(--gold)`). No hex in JS except inside theme objects.
- **Never break localStorage keys.** If a key changes shape, add a boot-time migration (see `_migrateToV2` pattern ~line 170).
- **Cache-bust on every JS/CSS edit.** Increment `?v=N` on `dashboard.css` and `dashboard.js` script tags in `index.html`.
- **`appState` schema is sacred.** Never change the shape of `.trades.items` or `.filters.chips` without updating all read sites.
- **One fix = one commit.** No scope creep. Visible dashboard text in English.
- **Validate before delivery:** `node -c dashboard.js` + confirm brace balance (count `{` vs `}` = 0 delta).
- **Test in browser before pushing.** No CI — open locally and verify the golden path.

## 10. Common Pitfalls

1. **Stale API cache.** After structural normalization changes, purge `apiTradesCache_v2_rrmax_*` + hard refresh.
2. **`gs_hidden_widgets` is global** (not per-preset). Layout Reset/wipe does not touch it.
3. **Share-view PNG is pinned** at 2400×1032 → 4800×2064 @scale=2. Never touch `flex` on `#sv-export`. Never add `vw/cqw/clamp()` to share-view selectors.
4. **`isBE` is mode-dependent.** `bes ≠ be` in `calcStats`: `be = be_tp + be_sl` (Notion-pure), `bes = trades.filter(isBE).length` (effective, mode-dependent).
5. **Mini-sidebar GridStack 10.3.1 bug.** `acceptWidgets` corrupts state. Fix: DOM container swap + `_isReiniting` flag. Always use `grid.load()` on a fresh container.
6. **Typography independence in share-view.** Never apply `var(--typo-*)` or `var(--fs-*)` inside share-view selectors — they shift with the theme editor and break PNG consistency across machines.
7. **XSS SEV-HIGH (audit 2026-05-17).** `t.pair/outcome/obstacles[]` are interpolated raw in innerHTML at 6 sites. See `docs/current-roadmap.md §H1` for the fix list.
8. **Ghost trades (audit H2).** Deleted Notion trades are never purged from local cache. Only a full sync can detect deletions.
9. **`no-be` mode was removed.** Boot migration silently folds it to `be-fallback`. Do not re-add it.
10. **TPM ↔ ORR widget mutual exclusion** is enforced in code. Do not bypass it.
11. **`_liveSectionLayouts[sec]` can be stale** after hide/unhide ops. `_msOpenSidebar` reads directly from `_grid.getGridItems()` for truth.
